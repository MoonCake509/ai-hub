# Правила работы в репозитории AI-Hub

Проект: оркестратор AI Hub (хаб, воркеры, веб-панель).
Эти правила действуют для людей и для агентов (Codex, Claude Code, Hermes).

## Фронтенд

0. Визуальный эталон проекта — `docs/DESIGN.md` (палитра, свет, компоненты, движение).
   Это утверждённый владельцем персональный дизайн AI Hub: любой агент обязан его соблюдать
   и не возвращать плоский одноцветный тёмный вид. Значения берутся из `web/styles.css`,
   замысел и правила — из `docs/DESIGN.md`. Приёмка UI — визуальное «да» владельца и скриншот
   до/после, а не только цифры контраста.
1. Перед задачей по интерфейсу сначала получить руководство, а не писать по памяти:
   `npx modern-web-guidance@latest search "<тема>"`, затем
   `npx modern-web-guidance@latest retrieve <id>`.
   Навык установлен в `.agents/skills/modern-web-guidance` (каталог не хранится в git;
   установка на новой машине: `npx modern-web-guidance@latest install`).
2. После правок в `web/` прогнать `npx modern-web-guidance@latest legacy-scan web`
   и не оставлять новых находок без объяснения.
3. Стек — обычные HTML/CSS/JS без сборки. Сначала платформенное решение,
   потом лёгкий запасной вариант; новые фреймворки и тяжёлые полифилы не добавляем.
4. Правила проекта и решения в `docs/decisions` главнее рекомендаций навыка.

## Общее

- Не менять поведение приёмки и аренды заданий без отдельного решения в `docs/decisions`.
- Секреты, токены и содержимое сессий не попадают в код, логи и артефакты.
- Живой журнал работ — `backlog/BACKLOG.md`; разборы — `docs/`, баги — `bugs/`.
