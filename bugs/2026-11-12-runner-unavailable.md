# Блокер приёмки: на хосте нет изолированного исполнителя проверок

**Дата:** 12.11.2026
**Где:** `R:\AI-Hub`, стенд `http://127.0.0.1:8102`, воркер `WIN-V76QC2G60Q1`
**Статус:** открыт, требует решения владельца

## Что не работает

Сценарий 2 документа («одна реальная задача через FLOW: тест, ревью, черновик PR, END») не запускается:

```
POST /runs → 409
{"code":"runner_unavailable",
 "message":"Воркер проекта не подтвердил готовность изолированного исполнителя проверок."}
```

## Причина

`agents/laptop/workspace_host.py:capabilities()` убирает `run_checks` из объявленных операций,
если не задан `AIHUB_ISOLATED_RUNNER_ARGV`. Сам исполнитель `tools/docker_check_runner.py`
начинается с требования `os.name == 'posix'` (`validated()`), то есть рассчитан на Linux-хост
с Docker и монтированием снимка в контейнер. На Windows-хосте он не запускается, поэтому
`run_checks` не объявлен, а `runs.create_run` без плана проверок отказывает.

## Что уже проверено

- Прямой вызов `run_checks` на этом хосте невозможен: операции нет в `workspace_ops` (подтверждено `/workers`).
- Обход через обычный `apply_patch` нельзя: гейт `flow_gates` требует receipt изолированного runner'а,
  иначе тестер/ревьюер не проходят.
- Остальные сценарии приёмки этим блокером не затронуты: создание проекта с повтором (1) и
  обслуживание архива (3) проходят, см. `tools/accept_project_flow.py`.

## Варианты решения (нужно выбрать)

1. **Linux-хост для проверок.** Поднять на сервере `147.45.109.41` воркер с
   `AIHUB_ISOLATED_RUNNER_ARGV` на `docker_check_runner.py` и образом проверок; хаб отправляет
   `run_checks` туда, проект остаётся на Windows. Даёт полноценный сценарий 2.
2. **Docker Desktop как runner.** Запускать `docker_check_runner.py` внутри Linux-контейнера
   Docker Desktop и пробрасывать каталог проекта томом. Требует аккуратной настройки путей
   `R:\` → `/managed/snapshots` и отдельной проверки изоляции.
3. **Признать сценарий 2 вне текущего хоста** и принимать FLOW-задачи без программных проверок
   (только ревью модели). Это ослабляет гейты — не рекомендую.
