## Правила, из-за нарушения которых была потеря данных

1. Запускать прод только так: `cd /mnt/r/AI-Hub/infra && docker compose -p aihub --env-file .env up -d`. Имя проекта не менять: оно определяет префикс томов (теперь том зафиксирован по имени `aihub_pgdata`, но привычку менять `-p` надо оставить).
2. Стенд — только с явным файлом: `docker compose -p aihub-core03 -f docker-compose.core03.yml --env-file .env.core03 up -d`. Без `-f` compose берёт прод-описание из `docker-compose.yml` и создаёт посторонние тома и контейнеры.
3. Перед любым `up` с новым именем проекта смотреть `docker compose config | sed -n '/^volumes:/,$p'` — там должно быть `name: aihub_pgdata`.
4. Новая директория проекта заводится только внутри `R:\AI-Hub\workspace\`, с датой создания в этом файле.
5. Каталог `workspace/` в git не попадает (`.gitignore`), чтобы стенд и архив не смешивались с прод-репозиторием.
