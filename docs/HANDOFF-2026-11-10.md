## Грабли (проверено болью)

- DrvFs (R:) отдаёт git устаревший кэш после записи → писать через `os.replace`,
  проверять `git diff` после каждой записи.
- `web/index.html` и `hub/app/main.py` — CRLF; правки нормализовать обратно, иначе diff шумный.
- Из контейнера хаба хостовые сервисы (127.0.0.1:8787 OCR, :9333 CDP, :11434) TCP принимают,
  но HTTP молчит — ложный timeout. litellm:4000 честно даёт 401.
- Тесты: pytest в контейнере НЕТ — unittest (`docker cp test.py aihub-hub-test:/tmp/`,
  затем `cp /tmp/x.py /app/x_test.py && cd /app && python -m unittest x_test -v`).
  `test_server_ocr_prompt.py`/`test_outbox_delivery.py`/`test_bridge_codex_executable.py`
  требуют `agents/*/worker_v2.py` и Windows (`msvcrt`) — в Linux-контейнере не бегут.
- `test_core02b_fair.py` соревнуется с живым воркером за очередь — гонять сразу после
  постановки или при остановленном воркере. `test_core02b_live.py` сам ломает fixture
  к «до правки» состоянию.
- Длинные heredoc через terminal обрезаются — файлы писать частями или base64-бандлом
  (`hex`-имя + hex-данные через `python -c "import sys;..."` по stdin).
- Перед тестами на стенде: отменить незавершённые задания и почистить аренды, иначе
  аренда утащит чужое задание прошлых прогонов.
- Чужое, НЕ трогать: `infra/docker-compose.test.yml` (M), `infra/stand92.bat`, `models/`,
  `tools/netwatchdog.ps1`, `tmp/`, `*.bak-core02b`.
