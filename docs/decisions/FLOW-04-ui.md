# FLOW-04: интерфейс процесса

**Статус:** принято 2026-11-10.

## Решение

Панель «Запуски процесса» во вкладке наблюдений: список запусков с прогрессом
(`готово из всего`, текущий шаг), кнопки «Выполнить шаг», «Пауза», «Продолжить»,
«Отменить». Состояние читается из базы при каждом открытии — браузер ничего не
держит, закрытие вкладки процесс не теряет. Каждая кнопка вызывает реальный
эндпоинт контроллера; заглушек нет.

## Проверено

- `GET /runs` отдаёт список с прогрессом (200, пустой список на проде).
- DOM-регресс `tests/dom-core03-ui.cjs` проходит после правки разметки.
- Кнопки привязаны к `POST /runs/{id}/dispatch|pause|resume|cancel`.

## Ограничение

Живой сценарий «нажал — сходил в агент — увидел результат» требует работающего
изолированного исполнителя проверок (`run_checks` в проде пока недоступен),
поэтому проверен на стенде.
