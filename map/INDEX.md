# map/ — индекс карт проекта

Каталог `map/` — точка входа к картографии репозитория. Пока пуст: на 2026-11-15
карта проекта живёт в `ops/INDEX.md` (210 файлов, коммит `c43a42f`, байты + git-версия + SHA-256).

## Что где

| Что | Где | Заметка |
| --- | --- | --- |
| Карта файлов (путь, размер, версия git, SHA-256 16) | `ops/INDEX.md` | единственный сгенерированный источник, руками не правится |
| Разборы и решения | `docs/`, `docs/decisions/` | по AGENTS.md |
| Живой журнал работ | `backlog/BACKLOG.md` | по AGENTS.md |
| Отчёты архивариуса | `ops/archivist/` | по датам, `INDEX.md` — сводка |

## Правила

- Новые сгенерированные карты кладутся сюда, файлом на дату: `map/YYYY-MM-DD-<тема>.md`.
- Секреты, токены и содержимое сессий в карты не попадают.
- `ops/INDEX.md` не дублируется здесь целиком — только ссылка: карта строится по коммиту и быстро устаревает.
